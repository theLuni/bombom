# BOMBOM — 3D-шутер в браузере (аналог CS2) с RPG-прокачкой

Тактический шутер от первого лица прямо в браузере: раунды, закладка/разминирование бомбы,
две точки, экономика и закупка — плюс полноценная RPG-петля (опыт, уровни, три ветки навыков,
лут с редкостями, способности и боссы).

Никаких внешних ассетов: вся геометрия строится кодом, текстуры рисуются на canvas,
звук синтезируется через WebAudio. Зависимость всего одна — `three`.

## Быстрый старт

```bash
npm install
npm run dev          # http://localhost:5173
```

Сборка и предпросмотр продакшн-версии:

```bash
npm run build        # dist/
npm run preview      # http://localhost:4173
```

Требуется браузер с WebGL2 (Chrome, Edge, Firefox, Safari 16+).

## Управление

| Клавиши | Действие |
| --- | --- |
| ЛКМ | огонь (автоматический для авто-оружия) |
| ПКМ | прицел (у снайперок — оптика, сильное приближение) |
| WASD | движение, `Space` — прыжок, `Ctrl`/`C` — присесть |
| `Shift` | рывок (способность «Рывок», перезарядка ~5 с) |
| `F` | аптечка-дрон (лечение, перезарядка 22 с) |
| `R` | перезарядка |
| `1` `2` `3` | основное / пистолет / нож, `Q` — быстрая смена |
| `4` `5` `6` `7` | гранаты: ХЕ, дымовая, световая, зажигательная |
| `E` | удерживать для разминирования бомбы |
| `B` | магазин (закупка), `P` — дерево навыков |
| `Tab` | сводка по операции и статистика |
| `Esc` | пауза / меню |

## Правила раунда

- Игрок — спецназ (CT), против него волна террористов.
- Победа: уничтожить всех врагов **или** разминировать бомбу, если её успели заложить
  (разминирование — удерживать `E` рядом с бомбой, 5 секунд; с набором сапёра — быстрее).
- Поражение: бомба взорвалась **или** игрок погиб.
- Раунд: 11 секунд закупки, затем 2:15 боя; после закладки — 40 секунд до взрыва.
- За поражение теряется одна жизнь (всего их три). Жизни кончились — операция завершена,
  но опыт, уровень и навыки сохраняются навсегда.
- Каждый 5-й раунд — «тяжёлый боевик»: миниган, много здоровья, отдельная модель.
- Награды: победа 3200, поражение 1600, фраг 350, хедшот +120, разминирование 450.

## RPG-система

**Опыт и уровни.** Опыт дают фраги, хедшоты, победы в раундах, закладки и разминирования.
Каждый уровень — очко навыка и выбор одного из трёх случайных предметов лута (пауза с картами).

**Три ветки навыков** (по 6 навыков, у каждого несколько рангов, клавиша `P`):

- **Штурм** — урон, скорострельность, разброс, хедшоты, бронебойность, ярость (урон растёт в бою).
- **Техника** — здоровье, регенерация, броня, надёжность, скорость перезарядки, урон гранат.
- **Разведка** — скорость бега, прыжок, тишина (враги хуже слышат), аптечка-дрон, рывок, «второе дыхание».

**Лут** четырёх редкостей (обычное / редкое / эпическое / легендарное) даёт бонусы на текущий
забег: лечение, броня, патроны, гранаты, кредиты, временные баффы (берсерк, точность, адреналин),
критический урон, вампиризм, усиление ствола и другое.

**Гранаты и способности:** рывок с неуязвимостью, аптечка-дрон, второе дыхание, огонь по площади,
дымовая завеса (реально перекрывает обзор и ботам, и игроку), слепящая вспышка.

## Арсенал и экономика

Оружие покупается в магазине на кредиты и открывается по мере роста уровня:
пистолеты (Удар-9, Магнум-50, Кольт-Ангел), ПП (Шершень-5, Стикс-90, Вектор-45),
автоматы (АКМ-47, М4-Кобра, Авгур-77, Скарабей-17), снайперки (Дальний-АВМ, Гаусс-Хищник),
дробовики (Дробовик-12, Авто-Дробовик-20, Плазма-разряд) и миниган «Шквал-6».
У каждого ствола свои урон, разброс, отдача, пробитие брони, вес и стиль модели,
а также редкость. В магазине также броня, аптечки, набор сапёра, патроны и все четыре гранаты.

## Карта «de_БОМБОМ»

80×80 метров: спавн спецназа на юге, спавн террористов на севере, мид с двойными проходами,
«склады» по флангам, два этажа на одной из построек и две точки закладки (A и B) с укрытиями.
Карта описана тайловой сеткой (`src/world/layout.js`), из неё автоматически строятся геометрия,
коллайдеры, навигационная сетка для ботов и миникарта.

## Проверки без браузера

Игра проверяется полностью без графического драйвера — на заглушках DOM и canvas:

```bash
npm run check        # всё сразу
npm run check:map    # связность карты, маршруты ботов, точки закладки
npm run check:sim    # стрельба, урон, хитбоксы, бомба, разминирование, лут, навыки, магазин, гранаты
npm run check:play   # полный автопрогон операции: раунды, потери жизней, босс, покупки
npm run check:ui     # интерфейс в эмуляции DOM: все экраны и события HUD
npm run check:boot   # запуск main.js целиком: кадры игрового цикла, ввод, бомба, оверлеи
```

`check` использует `jsdom` (devDependency) и заглушку `WebGLRenderer`, поэтому проходит
без GPU и без браузера — так и разрабатывалась игра в среде без графики.

## Как всё устроено внутри

- **Физика** — собственные AABB-коллайдеры: движение со скольжением, шаг по ступенькам,
  трассировка лучей по методу slab (для попаданий, укрытий и видимости ботов).
- **Навигация** — сетка 2 м, BFS-поля расстояний от цели, боты идут по градиенту,
  не срезают углы и умеют обходить укрытия; на каждой карте проверяются все маршруты.
- **ИИ ботов** — зрение с конусом и проверкой видимости, слух по шуму (выстрелы, шаги, взрывы),
  реакция, ошибка прицеливания, очередь и паузы, стрейф в бою, закладка бомбы и оборона после неё.
- **Оружие** — отдельная сцена и камера (`viewScene`) рендерятся поверх мира с очисткой буфера
  глубины, поэтому ствол никогда не проваливается сквозь стены; отдача, покачивание, прицел,
  перезарядка с анимацией магазина.
- **Интерфейс** — обычный DOM поверх canvas, состояние приходит через шину событий (`src/core/bus.js`).
